# rate-path — 市場金利から利上げ・利下げの時期を出す計算

国債利回りのカーブから、中央銀行の会合ごとの政策金利パス（階段関数）を
復元し、「次の会合で動く確率の目安」「半分以上見込む会合」「見込みきる
会合」「1 年後までの累計回数」を読み取るツール。ダッシュボードの
「利上げ・利下げの時期」パネルの計算（`macro/rate_path.py`）の仕様を
そのまま実装したもの。

## 考え方

国債の利回り y(T) は、満期までの翌日物金利（政策金利にほぼ等しい）の
平均の見込みに近似できる。政策金利は会合の翌日にしか変わらないので、
見込みのパスは会合ごとの階段関数になる。

```
y(T) ≒ (1/T) [ r0*min(T, t1) + Σ_k x_k * l_k(T) ]
l_k(T) = max(0, min(T, t_{k+1}) - t_k)
```

各年限の利回りに最も合う階段 x_k を、罰則付き最小二乗で解く。

```
最小化: Σ_j (W w_j)^2 (y_j - ŷ(T_j))^2 + λ^2 [ (x1 - r0)^2 + Σ_{k>=2} (x_k - x_{k-1})^2 ]
  W = 100、w_j = min(1, T_j / 0.5)
  λ: 米国 100 / 日本 6.25
```

前半が利回りへの当てはめ、後半が「隣の会合との差」を小さくする平滑化で、
年限が足りない遠い先をなめらかに埋める。w_j は満期の近い国債ほど
小さくする重み（小さな値動きで利回りが大きく飛ぶため）。

会合 k の段差から、FedWatch と同じ考え方で回数を読む。

- p_k = (x_k − x_{k−1}) / 0.25% … その会合で動く確率の目安
- N_k = (x_k − r0) / 0.25% … その会合までの累計回数
- 「半分以上見込む会合」= N が初めて 0.5 回以上になる会合
- 「見込みきる会合」= N が初めて 1.0 回以上になる会合
- 前の会合が 0.3〜0.5 回、または半分を超えた会合が 0.7 回未満なら
  「どちらとも言えない」（2 つの会合で割れている）

## 入力データ

| | 利回り | r0（いまの政策金利の目安） |
|---|---|---|
| 米国 | FRED の国債金利 DGS（1・3・6 か月、1・2・3 年。米財務省の日次パーイールドと同系統の H.15 ベース） | SOFR × 365/360 |
| 日本 | 財務省の国債金利（1・2・3 年）＋ 日本証券業協会の売買参考統計値（国庫短期証券・残り 1.5 年以内の国債） | 無担保コール翌日物（日銀時系列統計 FM01 / STRDCLUCON） |

会合の日程は FRB と日本銀行の公表分をコードに内蔵し、知られていない
先の会合は過去の間隔（中央値）で補う。

## 使い方

```
python3 macro/rate_path.py              # 日米両方
python3 macro/rate_path.py --jp         # 日本だけ
python3 macro/rate_path.py --us --verbose   # 会合ごとの表も出す
python3 macro/rate_path.py --json       # 機械可読な出力
```

依存: Python 3 + numpy。データ取得は curl コマンド経由（この実行環境では
FRED 等が Python 系 HTTP クライアントの User-Agent に応答しないため）。

## ダッシュボード表示との照合（2026-11-26）

ダッシュボード側の計算（2026-11-25 データ、11-26 19:17 計算）と、
本実装の実行結果の比較。

| | ダッシュボード | 本実装 |
|---|---|---|
| 米国 r0 | 4.00% | 3.99% |
| 米国 次の会合（12/9）の p | 128% | 89% |
| 米国 半分 / 見込みきる | 12/9 / 12/9 | 12/9 / 2027-01-27 |
| 米国 1 年後まで | +2.6 回 | +2.8 回 |
| 日本 r0 | 1.23% | 1.23% |
| 日本 次の会合（12/18）の p | 27% | −3〜−18% |
| 日本 半分 / 見込みきる | 2027-01-22 / 2027-03-18 | 2027-01-22 / 2027-03-18（一致） |
| 日本 1 年後まで | +2.4 回 | +2.2〜+2.9 回 |

半分・見込みきる会合と 1 年の累計回数はほぼ一致する。一方、**次の会合の
p は再現が最も不安定**で、ずれる理由は 2 つある。

1. 米国: 本実装は FRED の DGS（6 点）を使うため、財務省パーイールドの
   1.5・2・4 か月（短期のピン留めになる点）が欠ける。
2. 日本: 国庫短期証券は担保・需給の都合で無担保コールレートを下回って
   取引される（例: 2026-11-30 償還分 1.200% vs コール 1.227%）ため、
   直近会合の段差が下向きに引っ張られる。

## 注意

- 国債の利回りには期間プレミアムや需給のゆがみが乗るので、回数・確率は
  目安。金利先物・OIS から出す市場の織り込み（FedWatch など）とはずれる。
- 解は平滑化 λ の置き方に依存する。観測点より会合の数がはるかに多く、
  遠い先ほど「データ」より「なめらかさの仮定」で決まる。
## OIS 版（macro/rate_path_ois.py）

同じ階段フィットを、国債利回りの代わりに OIS（翌日物金利スワップ）の
固定金利へ適用したものが `macro/rate_path_ois.py`。

### 国債版との違い

OIS の固定金利は、その期間の翌日物金利を複利で積み上げたものの期待値と
ほぼ一致するよう裁定が働く。つまり「満期までの政策金利の平均の見込み」
そのものが市場で取引されている。国債の利回りはこれに期間プレミアムや
需給・流動性の値段（国庫短期証券の担保としての品薄プレミアムなど）が
混ざったもので、フィットはその混ざり物まで階段 x_k に吸収させるため、
織り込みの読みにバイアスが乗る。

- 期間プレミアムがプラスなら利上げを過大に読む（1 年の累計回数など）
- 国庫短期証券の品薄プレミアムはフロントエンドを下に引っ張り、
  直近会合の p を過小（マイナスにも）にする

もう 1 つの違いは点の細かさ。OIS は 1 か月・3 か月・6 か月…と年限が
細かく、会合日ぴったりのフォワードも抜けるので、平滑化への依存が
小さくて済む。こちらでは λ は日米とも 6.25 に置く（国債版の米国
λ=100 では、最初の会合の段差が平滑化で潰れてしまう）。

### 確率の読み方

会合をまたぐ区間のフォワードから会合後の水準 x を逆算し、
p = （x − r0）/ 0.25% と読む。rate_path の p_k と同じ読み替えで、
「据え置きか ±0.25% か」の二択を仮定したリスク中立の期待値であり、
確率そのものではない（50bp の動きが半分の確率で織り込まれていても
同じ数字になる）。分布まで知るには金利オプションが要る。

### データの入手性

OIS カーブの毎日の値は公式には公表されず、通常は Bloomberg 等の
有料データでしか手に入らない（日銀も TONA OIS カーブは公表していない）。
本スクリプトは、公開ページで日次値を出している BlueGamma
（インターディーラー・ブローカーの気配からカーブを構築する第三者）の
表を使う。

- 米国 SOFR OIS: https://www.bluegamma.io/usd-swap-rates
  （1M / 3M / 1Y / 2Y / 3Y。6M の掲載なし）
- 日本 TONA OIS: https://www.bluegamma.io/swap-rates/tona-swap-rates
  （1M / 3M / 6M / 1Y / 2Y / 3Y）

第三者の集計値なので、絶対水準は割り引いて見ること。日本の 1M・3M は
年末をまたぐ時期には越年プレミアムが乗り、直近会合の読みを少し
膨らませる可能性がある。

```
python3 macro/rate_path_ois.py            # 日米とも
python3 macro/rate_path_ois.py --compare  # 国債版も走らせて比較表示
```

### 国債版との比較（2026-11-25 引け値）

| | 国債版 | OIS 版 |
|---|---|---|
| 米国 次の会合（12/9）の p | 89% | 103% |
| 米国 半分 / 見込みきる | 12/9 / 2027-01-27 | 12/9 / 12/9 |
| 米国 1 年後まで | +2.8 回 | +2.4 回 |
| 日本 次の会合（12/18）の p | −11% | 61% |
| 日本 半分 / 見込みきる | 2027-01-22 / 2027-03-18 | 2026-12-18 / 2027-01-22 |
| 日本 1 年後まで | +2.9 回 | +2.1 回 |

- 米国は OIS のほうが「12 月でほぼ 1 回分」に寄る。最短年限（1M）だけ
  からの直接逆算でも 12/9 は約 106% で、フィットの裏づきが取れる。
- 日本は絵が変わる。OIS では 12 月会合が 6 割超の織り込みで、1 回分に
  達するのは 1 月。国債版で 12 月がマイナスだったのは、国庫短期証券の
  品薄プレミアムでフロントが潰れていたことが主因と考えられる。
- 1 年の累計は OIS のほうが両国とも少ない。国債版には期間プレミアムの
  上乗せが含まれていた分と見られる。

## バックテスト（macro/rate_path_backtest.py / rate_path_eval.py）

過去の各月末を「その日」としてパスを復元し、その後 1 年の実際の
政策金利と比べる。会合日程は実際のカレンダー（後知恵）を使う。

```
python3 macro/rate_path_backtest.py   # data/backtest_results.csv を作る
python3 macro/rate_path_eval.py       # 集計を表示
```

結果（米国 2019-01〜2025-10 の月末 82 件 / 日本 2024-01〜2025-10 の 22 件）:

| | 米国 | 日本 |
|---|---|---|
| N(1y) バイアス | −1.35 回（過小に織り込む） | −0.37 回 |
| N(1y) MAE | 3.59 回 | 0.72 回 |
| N(1y) 相関 | 0.83 | 0.26 |
| 方向の的中（実績 ≥1 回の局面） | 91% | 100%（全件が利上げ局面） |
| 半分超え会合のタイミング誤差 | 中央値 0 日 / ±45 日以内 56% | 中央値 +35 日（予想が遅め）/ ±45 日以内 45% |
| p1 ≥75% のとき実際に次の会合が動いた割合 | 100%（12/12） | ―（該当なし） |
| p1 ≤25% のとき実際に動いた割合 | 23% | 9% |

読み方:

- 累計回数の水準は割り引いて見ること。特に米国は 2022 年の利上げを
  市場（とこの計算）が大幅に過小評価したことが MAE を押し上げている。
- 方向と「半分超え」のタイミングはまずまず当たる。日本の半分超えは
  実際の初動より遅れ気味（+35 日）。
- p1 は確率として較正されていない。低くても 2 割前後は実際に動く
  （段差を複数会合に分散して読むため）。「次の会合の p」は
  ダッシュボード表示でも最も割り引いて読むべき数字。

## 方法の出どころ

この組み立て自体の単一の元論文はない。土台は Söderlind & Svensson
(1997, *Journal of Monetary Economics*) の「金融商品の価格から市場の
期待を抽出する」系譜と、CME FedWatch の会合別確率の考え方で、
ステップ関数で会合ごとの織り込みを出す発想に最も近い先行事例は
スウェーデン中銀のスタッフメモ Ceh (2022) "How much is priced in?
Market expectations of monetary policy lift-off"（ただし入力は先物）。
