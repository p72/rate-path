# rate-path — 市場金利から利上げ・利下げの時期を出す計算

国債利回りのカーブから、中央銀行の会合ごとの政策金利パス（階段関数）を
復元し、「次の会合で動く確率の目安」「半分以上見込む会合」「見込みきる
会合」「1 年後までの累計回数」を読み取るツール。ダッシュボードの
「利上げ・利下げの時期」パネルの計算（`macro/rate_path.py`）の仕様を
そのまま実装したもの。

## 考え方

国債の利回り y(T) は、満期までの翌日物金利（政策金利にほぼ等しい）の
平均の見込みに近似できる。政策金利は会合の翌日にしか変わらないので、
見込みのパスは会合ごとの階段関数になる。

```
y(T) ≒ (1/T) [ r0*min(T, t1) + Σ_k x_k * l_k(T) ]
l_k(T) = max(0, min(T, t_{k+1}) - t_k)
```

各年限の利回りに最も合う階段 x_k を、罰則付き最小二乗で解く。

```
最小化: Σ_j (W w_j)^2 (y_j - ŷ(T_j))^2 + λ^2 [ (x1 - r0)^2 + Σ_{k>=2} (x_k - x_{k-1})^2 ]
  W = 100、w_j = min(1, T_j / 0.5)
  λ: 米国 100 / 日本 6.25
```

前半が利回りへの当てはめ、後半が「隣の会合との差」を小さくする平滑化で、
年限が足りない遠い先をなめらかに埋める。w_j は満期の近い国債ほど
小さくする重み（小さな値動きで利回りが大きく飛ぶため）。

会合 k の段差から、FedWatch と同じ考え方で回数を読む。

- p_k = (x_k − x_{k−1}) / 0.25% … その会合で動く確率の目安
- N_k = (x_k − r0) / 0.25% … その会合までの累計回数
- 「半分以上見込む会合」= N が初めて 0.5 回以上になる会合
- 「見込みきる会合」= N が初めて 1.0 回以上になる会合
- 前の会合が 0.3〜0.5 回、または半分を超えた会合が 0.7 回未満なら
  「どちらとも言えない」（2 つの会合で割れている）

## 入力データ

| | 利回り | r0（いまの政策金利の目安） |
|---|---|---|
| 米国 | FRED の国債金利 DGS（1・3・6 か月、1・2・3 年。米財務省の日次パーイールドと同系統の H.15 ベース） | SOFR × 365/360 |
| 日本 | 財務省の国債金利（1・2・3 年）＋ 日本証券業協会の売買参考統計値（国庫短期証券・残り 1.5 年以内の国債） | 無担保コール翌日物（日銀時系列統計 FM01 / STRDCLUCON） |

会合の日程は FRB と日本銀行の公表分をコードに内蔵し、知られていない
先の会合は過去の間隔（中央値）で補う。

## 使い方

```
python3 macro/rate_path.py              # 日米両方
python3 macro/rate_path.py --jp         # 日本だけ
python3 macro/rate_path.py --us --verbose   # 会合ごとの表も出す
python3 macro/rate_path.py --json       # 機械可読な出力
```

依存: Python 3 + numpy。データ取得は curl コマンド経由（この実行環境では
FRED 等が Python 系 HTTP クライアントの User-Agent に応答しないため）。

## ダッシュボード表示との照合（2026-11-26）

ダッシュボード側の計算（2026-11-25 データ、11-26 19:17 計算）と、
本実装の実行結果の比較。

| | ダッシュボード | 本実装 |
|---|---|---|
| 米国 r0 | 4.00% | 3.99% |
| 米国 次の会合（12/9）の p | 128% | 89% |
| 米国 半分 / 見込みきる | 12/9 / 12/9 | 12/9 / 2027-01-27 |
| 米国 1 年後まで | +2.6 回 | +2.8 回 |
| 日本 r0 | 1.23% | 1.23% |
| 日本 次の会合（12/18）の p | 27% | −3〜−18% |
| 日本 半分 / 見込みきる | 2027-01-22 / 2027-03-18 | 2027-01-22 / 2027-03-18（一致） |
| 日本 1 年後まで | +2.4 回 | +2.2〜+2.9 回 |

半分・見込みきる会合と 1 年の累計回数はほぼ一致する。一方、**次の会合の
p は再現が最も不安定**で、ずれる理由は 2 つある。

1. 米国: 本実装は FRED の DGS（6 点）を使うため、財務省パーイールドの
   1.5・2・4 か月（短期のピン留めになる点）が欠ける。
2. 日本: 国庫短期証券は担保・需給の都合で無担保コールレートを下回って
   取引される（例: 2026-11-30 償還分 1.200% vs コール 1.227%）ため、
   直近会合の段差が下向きに引っ張られる。

## 注意

- 国債の利回りには期間プレミアムや需給のゆがみが乗るので、回数・確率は
  目安。金利先物・OIS から出す市場の織り込み（FedWatch など）とはずれる。
- 解は平滑化 λ の置き方に依存する。観測点より会合の数がはるかに多く、
  遠い先ほど「データ」より「なめらかさの仮定」で決まる。
- 精度の検証用に、過去の決定と比べる `rate_path_backtest.py` /
  `rate_path_eval.py` を別途用意する想定（未実装）。

## 方法の出どころ

この組み立て自体の単一の元論文はない。土台は Söderlind & Svensson
(1997, *Journal of Monetary Economics*) の「金融商品の価格から市場の
期待を抽出する」系譜と、CME FedWatch の会合別確率の考え方で、
ステップ関数で会合ごとの織り込みを出す発想に最も近い先行事例は
スウェーデン中銀のスタッフメモ Ceh (2022) "How much is priced in?
Market expectations of monetary policy lift-off"（ただし入力は先物）。
